# PRONO DIVIN

Application web de démonstration pour afficher des pronostics de football et de tennis.

## Installation

1. Installe Node.js.
2. Ouvre un terminal dans ce dossier.
3. Exécute :

```bash
npm install
```

4. Copie `.env.example` vers `.env`.
5. Ajoute ta clé API Football si tu en as une.
6. Lance :

```bash
npm start
```

7. Ouvre `http://localhost:3000`.

## Important

Sans clé API Football, l'application fonctionne en mode démonstration.

Les pronostics sont des estimations et ne garantissent jamais le résultat d'un match.
